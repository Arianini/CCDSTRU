# Tic Tac Toe in C

## Description
A console-based Tic Tac Toe game written in C that allows two players to take turns placing marks on a 3x3 board. The game checks for winning conditions and allows players to restart or exit the game.

## Features
- Two-player mode
- User-friendly board display
- Validates player input
- Detects win conditions and draw
- Option to replay after each game

## Gameplay Instructions
- Player 1 uses symbol `X`
- Player 2 uses symbol `O`
- Enter numbers 1–9 to place your mark on the board
- The goal is to get three of your symbols in a row
- The game ends in a draw if the board fills with no winner
- You can restart or exit after each game
